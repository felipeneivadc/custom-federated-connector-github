# Termos de uso

## Uso permitido

O GitHub Conector deve ser usado somente para consultas autorizadas a dados do
GitHub e em conformidade com as politicas da organizacao, do GitHub e do
Microsoft 365.

## Autorizacao

Cada usuario deve autenticar sua propria conta GitHub. O conector respeita as
permissoes combinadas do usuario e da GitHub App instalada no repositorio
selecionado.

## Limitacoes

O conector e destinado a leitura. Ele nao deve ser usado para criar, alterar,
mesclar, enviar ou excluir conteudo no GitHub.

## Responsabilidades

Usuarios sao responsaveis por validar respostas antes de tomar decisoes e por
nao inserir dados sensiveis em consultas alem do necessario. O acesso pode ser
suspenso se houver uso indevido ou risco de seguranca.

## Alteracoes e encerramento

O conector pode ser alterado, suspenso ou removido para atender requisitos de
seguranca, operacao ou conformidade. Alteracoes materiais destes termos devem
ser comunicadas conforme as obrigacoes aplicaveis.

> Estes sao termos operacionais iniciais e devem receber revisao juridica antes
> da disponibilizacao do conector fora do grupo piloto.
